# Alexa Smart Home Plus

Alexaに登録済みの機器を選び、Appleのホームアプリへ橋渡しするHomebridgeプラグインです。Homebridge 2では、対応機器を同じChild BridgeからMatterアクセサリとして公開することもできます。

設定ファイルを手作業で編集しなくても、Amazon認証、機器の取得、公開対象の選択までHomebridgeの設定画面で進められます。

[English](README.md) | [今後の予定](ROADMAP.md)

## 作成した背景

開発に使用した日本の`amazon.co.jp`環境では、Alexaの認証セッションが約1日後に利用できなくなり、手動での再認証が必要になる事象を確認しました。また、認証後に利用可能な機器名を設定画面へ自動反映し、公開対象を画面上で選びたいという目的もありました。

そこで本プラグインでは、認証状態を設定画面で確認できること、保存済みセッションを可能な範囲で自動更新すること、更新できない場合はブラウザ再認証へ分かりやすく誘導することを重視しています。

セッションの有効期間はAmazon側の仕様、アカウント、地域、認証条件によって変わる可能性があります。「約1日」は本開発環境で観測した事例であり、すべての`amazon.co.jp`アカウントに共通する保証値ではありません。

## このプラグインでできること

設定画面からAmazonへ接続すると、Alexaアカウントに登録されている機器と定型アクションを取得します。取得結果は検索や種類表示で絞り込み、HomeKitへ出したい項目だけを選択できます。

- Alexa機器の自動取得と再取得
- 機器名検索、種類表示、表示中項目の一括選択
- 同じ名前のAlexa機器を内部IDで区別して個別選択
- Alexa側の名称を変更しないHomeKit専用の別名
- 日本語／英語の設定画面と表示言語の自動判定
- 認証状態、取得処理、完了結果の画面内表示
- 物理操作や別リモコンによる変更を検出する定期状態確認（初期値は有効）
- Alexa定型アクションを一時的なHomeKitスイッチとして実行
- 未知の機器でもON/OFF操作が確認できればスイッチとして公開
- Homebridge 2で照明、ロック、コンセント、スイッチをMatterへ任意公開

## はじめて使うとき

### 1. Amazonへ接続

Homebridge UIでプラグイン設定を開きます。日本のアカウントではAmazonドメインに`amazon.co.jp`を選び、ブラウザから到達できるHomebridgeのホスト名またはIPアドレスを指定します。

認証プロキシのポートには、ほかのサービスが使用していない番号を設定してください。

`Alexaに接続`を押すとAmazonのログイン画面が開きます。ログイン、MFA、CAPTCHA、端末承認など、表示された確認を完了してください。認証完了ページが表示されたら、そのページを閉じてHomebridgeの設定画面へ戻ります。

### 2. HomeKitへ出す機器を選択

`機器を再取得`を押すと、Alexaから機器と定型アクションを取得します。通信に時間がかかっても設定画面は操作でき、完了後に一覧が更新されます。

一覧から公開対象を選択し、必要に応じてHomeKit用の別名を設定します。

### 3. 保存して反映

設定を保存してChild Bridgeを再起動します。選択した機器がAppleのホームアプリへ追加されます。

## HomeKitへの変換

Alexaが報告する種類と操作能力を見て、適切なHomeKitアクセサリへ変換します。

| Alexa側の機器 | HomeKitでの表示 | 主な操作 |
|---|---|---|
| 照明 | ライト | 電源、明るさ、色温度、対応機器のカラー |
| スマートロック | ロック | 施錠、解錠、状態取得 |
| コンセント／プラグ | コンセント | 電源 |
| スイッチ | スイッチまたはライト | 電源、対応機器の明るさ |
| ファン | ファン | 電源、対応機器の速度 |
| サーモスタット | サーモスタット | 温度と運転モード |
| 温度／湿度／空気質／COセンサー | 各種センサー | 状態取得 |
| Alexa定型アクション | 一時スイッチ | 定型アクションの実行 |

Alexa連携先やアカウントによって公開される操作能力が異なるため、同じ製品でも利用できる項目が変わる場合があります。

## Matter対応（Homebridge 2）

Matter対応は、HomeKit側ですでに利用しているAlexa認証、検出済み機器、操作処理、状態キャッシュをそのまま再利用します。Amazonセッションや定期ポーリングをMatter用に重複して作成することはありません。

### Matterを有効にする手順

すでにAlexa認証とHomeKitへ公開する機器の選択を完了している場合、その設定をMatterでも共用するため、認証や機器選択をやり直す必要はありません。初期設定がまだの場合のみ、先にAlexa認証、機器選択、設定保存を完了してください。

1. Homebridge UIでAlexa Smart Home PlusのChild BridgeにMatterを有効化します。
2. Child Bridgeを再起動します。
3. Homebridgeに表示されるMatterのコミッショニング情報に従い、対応するMatterコントローラへ追加します。

選択済み機器のうち対応するものが自動的に登録されます。MatterでもHomeKitと同じ公開対象とHomeKit用の別名を使用するため、Alexa機器を別の一覧で選び直す必要はありません。

| Alexa側の能力 | Matterでの種類 |
|---|---|
| 電源のみの照明 | On/Off Light |
| 調光／色温度／カラー対応照明 | 対応能力に応じたLight |
| スマートロック | Door Lock |
| スマートプラグ | On/Off Plug-in Unit |
| その他の安全な電源操作機器 | On/Off Switch |

Alexaが対応能力を報告している場合、電源、明るさ、色温度、カラー、施錠・解錠をMatterから操作できます。状態更新には既存のAlexa状態キャッシュと定期状態確認を共用します。

Homebridge 1では従来のHomeKitアクセサリだけを公開し、Matterレイヤーは自動的に使用しません。Matterのペアリングやコントローラ側の対応状況は、Homebridge 2と利用するMatter環境に依存します。センサー、サーモスタット、ファン、Alexa定型アクション、カメラ、Alexa固有機能のMatter変換は現時点では未対応です。同じ実機をHomeKitとMatterの両方から公開すると、両方の経路を取り込む環境では二重に見える場合があります。利用するコントローラに合わせて公開経路を選択してください。

### 定期状態確認

Alexa連携機器の中には、物理操作や別のリモコンで状態が変わってもイベントを通知しない機器があります。定期状態確認を有効にすると、10秒後、15秒後、30秒後、1分後、3分後、5分後、10分後、15分後に状態を取得し、その後は設定した間隔で継続します。定常時の初期値は5分で、1、3、5、10、15、30分から選べます。HomeKitから操作した場合はスケジュールを先頭から再開します。複数機器への問い合わせは分散され、一時障害時は最大60分まで間隔を自動的に延長します。

ただし、すべてのAlexa連携機器が現在状態の取得に対応しているわけではありません。機器や連携方式によっては、Alexaへ状態を問い合わせても状態が更新されない、古い値が返される、または状態情報自体が提供されない場合があります。その場合、HomeKitやMatterに表示される状態が実機の現在状態と一致しないことがあります。定期状態確認はAlexaが返した状態を反映する機能であり、Alexa側で更新されていない状態を強制的に再取得するものではありません。

### 実機で確認した構成

- Qrio Lock：施錠、解錠、現在状態
- Alexa登録照明：電源、明るさ、色温度、現在状態

## 認証情報とプライバシー

AmazonのユーザーID、パスワード、MFAコードをプラグイン設定へ入力する欄はありません。これらはAmazonが表示するログインページへ入力され、このプラグインは保存しません。

認証後は、Alexaへ継続接続するためのセッション情報だけをHomebridgeの`persist`領域に保存します。更新可能な間はセッションを自動更新し、再認証が必要になった場合は設定画面に接続操作を案内します。

## 困ったときの確認場所

### Amazonの画面が開かない

- 認証に使うHomebridgeホストが、操作中のブラウザから開けるか確認します。
- 認証プロキシのポートが別サービスと重複していないか確認します。
- Homebridgeを別端末やコンテナで動かしている場合は、その端末へ到達できるアドレスを使います。

### 機器取得が終わらない、または一覧が空

- Alexaアプリで対象機器を操作できるか確認します。
- 接続済み表示を確認してから`機器を再取得`を押します。
- 取得中でも画面を操作できます。少し待ってからもう一度取得できます。

### 保存した機器がホームアプリにない

- 公開対象にチェックが入っているか確認します。
- 設定保存後にAlexa Smart Home PlusのChild Bridgeを再起動します。
- センサーはアクセサリタイルではなく、部屋上部の状態欄に表示されることがあります。

## 対応環境

- HomeKitはHomebridge 1.x／2.x、MatterはHomebridge 2.1.1以降
- Node.js 18／20／22／24
- Homebridge Config UI Xを利用した初期設定を推奨

## 開発時の確認

```bash
npm ci
npm run verify
npm pack --dry-run --ignore-scripts
```

`verify`は単体テスト、Lint、TypeScriptビルドを順番に実行します。Amazonアカウントが必要な実機テストは通常の単体テストから分離しています。

## プロジェクトについて

Amazonが公開していない連携方式を使用する依存ライブラリがあるため、Amazon側の変更によって一時的に認証や操作が利用できなくなる可能性があります。本プロジェクトはAmazonおよび機器メーカーの公式製品ではありません。

本プロジェクトはMITライセンスの`joeyhage/homebridge-alexa-smarthome`を出発点とし、独自のパッケージ名、プラットフォーム名、設定画面、認証導線、機器選択機能を持つ派生プロジェクトです。元プロジェクトのREADME文章は転載していません。両方のプラグインで同じ機器を公開すると、HomeKitに重複して表示されます。
